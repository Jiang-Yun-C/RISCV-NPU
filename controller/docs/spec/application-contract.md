# T02 桌面应用语义合同 v3

## 范围与 T00 依赖

范围依据现有 T00/T20/T26 任务卡：单路 Qwen2.5-0.5B-Instruct、中文文本输入、温度/光照状态、LED 与 PWM 风扇控制。T02 在本合同中补齐所需的应用范围输入；T00 的赛事条款、开源复用资格和板型核实仍未完成，不据本次技术实验将 T00 标为 DONE。任务依赖按此范围作部分交付记录，T08/T32 仍须接收完整 T00。

本任务不连接或控制任何物理设备。`state_source=DESKTOP_SENSOR_FIXTURE` 表示桌面注入的数值快照，不表示真实传感器采集。T20 接虚拟外设，T26 再验收真实传感器。模型必须读取每个请求附带的状态；禁止将预期标签、参考动作或根据指令预计算的条件判断作为输入。

## 输入输出

输入包括中文指令与状态：`temperature`（摄氏度）、`light`（勒克斯）、`led`（0/1）、`pwm`（0–100 整数百分比）。测试快照是同步、有效的读数；陈旧/缺失/故障状态由 T20 定义，T02 不证明这些场景。

开发集前两轮显示三字段 JSON 易引入多余状态和矛盾错误码，因此在保留集评测前改为紧凑命令数组。测试标签继续使用下述规范化语义对象，动作、数值、顺序、读数和拒绝判定均不改变：

```json
{"actions":[["led",1],["pwm",50]],"readings":{"temperature":26},"error":null}
```

- `actions`：严格按要求顺序执行的写动作；保留先开再关等重复设备操作。led 只允许整数 0/1，pwm 只允许整数 0–100，不接受布尔值、字符串或小数参数。
- `readings`：仅包含明确查询的传感器值。名称为 temperature/light，数值必须与输入快照相同。没有查询时为空对象；回答中的必要信息就是该数值及其由固定字段定义的单位。自然语言回复渲染属于 T20，不计为模型自由文本能力。
- `error`：合法请求为 null；不支持的设备/传感器为 UNSUPPORTED；PWM 越界为 RANGE。拒绝必须是整条请求拒绝，动作和读数均为空；禁止执行混合请求的合法部分。v1 样例不混用两种错误，其优先级尚未验收。

灯、LED、指示灯同义；风扇对应 PWM；停转/半速/全速分别为 0/50/100。只执行明确要求的动作，禁止自行追加“合理”操作。条件按输入状态与显式阈值计算：`>`、`<`、`>=`、`<=`；无 else 且条件不满足则不操作。动作顺序与数值均由完整模型产生，评分器不修复、补全或替换它们。

模型实际输出示例为 `[["led",1],["pwm",50],["temperature",26]]`；拒绝为 `[["error","RANGE"]]` 或 `[["error","UNSUPPORTED"]]`，无操作为 `[]`。评分器仅按名称将显式命令拆分为 actions/readings/error，不推断或补全任何动作。非法 JSON、未知字段、重复读数、拒绝混有动作均失败。

v3 允许模型先输出简短判断说明，最后一行用 `RESULT=` 标记命令数组。评分器只接受完整 JSON 数组或唯一且位于末行的 RESULT=；说明不参与动作修正，动作错误仍失败。此调整仅依据开发集完成，保留集尚未评测。

## 数据与评测纪律

50 条开发集包含每类 10 条合法单指令/条件/多步/同义以及各 5 条非法设备/越界值。200 条保留集包含前四类各 40 条、后两类各 20 条。开发集与保留集的指令文字和措辞族不交叉；共享设备和 schema 是任务定义。生成器只创作样例和独立标签，不参与推理。

数据集在首次推理之前固定 SHA-256。开发阶段可调提示词；保留集只能在提示词、推理设置和评分器冻结后评估，不能根据其输出调参。后续量化也只使用开发集；T31 可按同一冻结协议作发布比较，不得据历史保留集失败追加专用提示。

这些是人工编写的有限模板及数值组合，包含同指令不同状态的成对样例；它们不是 200 个独立抽样用户意图，也不支持总体泛化率的统计推断。条件测试含相等边界。每一对要求文字相同、状态不同、预期动作不同，只有两例全部正确才算该对通过。

冻结于初次开发运行前的项目目标：合法任务完全成功率 ≥90%，非法任务正确拒绝率 ≥95%，分别报告分母与各类结果。格式不合法、额外动作/读数、动作遗漏/错序、错误读数、错误拒绝类型和未由 EOS 停止都算失败。失败样例必须保留；该目标为项目目标，不是赛事官方要求。

若完整范围不能达标，应记录真实结果及能力边界，在 T08 前明确收窄应用或另立模型变更；不得用量化或硬件加速掩盖语义失败。

## 复现与交接

模型来源为 [Qwen 官方仓库](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/tree/7ae557604adf67be50417f59c2c2f167def9a775)，精确文件清单见 [模型锁](t02-model-lock.json)。官方发布的是 BF16 权重；本任务完整加载并转换为 FP32 计算，不声称恢复发布前精度。无量化、微调、外部推理服务或规则替代模型。

向 T05/T07 交接实际模型配置、权重身份、生成 token 与算子结构；向 T20/T26 交接上述应用语义草案。T20 仍是控制意图合同最终负责人，必须检查输入有效性和模型输出、实施拒绝与执行日志；T02 的评分器不等同于生产设备安全控制器。
