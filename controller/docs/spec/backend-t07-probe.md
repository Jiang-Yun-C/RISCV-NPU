# T07 外存算子探针合同 v1

Producer=T07；consumers=T08/T13/T14/T15/T27。数值版本保持 `w8a8-g64-fp32-v1`，不修改 T05 阈值或模型身份。本文件定义可复跑评估探针，不冻结 T08 的运行时 ABI、T10 的物理模型包或 T15 的最终内核。

## 输入、构建与装载

配置入口为 `configs/t07-external.json`，指定已验收 T05/T06 证据目录。使用 T06 归档且核对 hash 的 `RvvCoreMiniAxi.zip`、Coral 源码中的 SRAM 存储模型及锁定 GCC/intrinsics。每次新建 VCS 构建目录重新编译 RTL 和固件；不复用 T06 的仿真可执行文件。GCC 位于 T06 工具缓存；清理缓存后先复建 T06。未启用 VME，不修改上游 RTL。

固件和预量化的 Aq/Sa 通过 Coral AXI 从口装入 8KiB ITCM / 32KiB DTCM，并完整回读。外存使用 T04 分页模型的 1GiB 窗口，模式标记 `PRELOAD`；仅输入数据和输出哨兵由测试台预置。实际读取、点积、FP32 恢复和结果写回均由真实 Coral RTL 执行。DPI 只实现 TCM SRAM 存储。

临时地址为 weights=0x80000000、Sw=0x82000000、bias=0x83000000、Y=0xA0000000、逐组 dot 校验区=0xA1000000；这些是测试布局，不是系统地址图。Aq/Sa 由 T05 提供；本探针不计入口动态量化，模型质量仍由 T11 验收。

## 内核和覆盖

权重逻辑布局为 W[N,K]，K 维每 64 元素一组；一次 RVV e8m4 加载一组，INT16 加宽乘积规约到 INT32。每个组的权重向量供 M 个 token 复用。每组按 T05 顺序先乘 Sa、再乘 Sw、跨组 FP32 累加，全部组结束后加一次 bias。编译禁止 FMA 和 fast-math。

运行 M=1 GEMV 与 M=4 GEMM，完整 Q、K、gate、down 矩阵分别覆盖 N×K=896×896、128×896、4864×896、896×4864。按 N 维每 128 行独立启动一次，所有输出行、全部 K 和全部组均实际执行并检查；累计周期是各块实测窗口之和，包含逐块启动开销，不声称是一趟连续全矩阵执行。每块最小权重流仍为 112KiB，超过 32KiB DTCM。主机可并行运行独立仿真进程，仅缩短验收墙钟时间，不把主机并发算作硬件并行。共享 head 只执行首块、中间块及 128 行尾块，保留全 K；全词表 594 块的耗时只能外推，不能写成全 head 执行实测。未单独执行 V/O/up，不能将形状覆盖写成全部模型算子验收。

标准数值案例额外写出每个 INT32 dot，独立检查器逐位对照 T05；最终 Y 同时满足逐元素和 NRMSE 门槛。校验写入占用真实 AXI/核心周期，必须计入测量并单列。K 投影另外关闭 dot 校验写入，以量化该探针开销；再关闭恢复和 Y 写入作有范围的差分诊断。后者不属于完整线性算子性能。

## AXI 与内存时序

共享内存模型扩展为可选 128 位数据、6 位 ID，不截断、不用隐含宽度转换。独立协议测试覆盖 0–63 的 ID、16 字节全拍、窄访问、burst、五通道反压、高地址与错误响应。T04 原有 32/64 位行为和默认时序保持兼容并重跑验收。

Coral 属性在测试台显式连接并逐周期检查：PROT=2、LOCK/CACHE/QOS/REGION=0；模型对应非独占、非一致性普通内存。不得用丢弃属性掩盖不支持的请求。记录实际 AR/AW SIZE/LEN、WSTRB 和有效字节；核心的单拍请求不能因内存模型支持 burst 就称为 burst 传输。

`TIMING_CONTROL=1` 才启用 T07 时序参数。latency 为地址接收至准备响应的附加等待，NBA 驱动使实际最早 R 握手还需一拍；interval 为每个读/写数据通道各自的最小服务间隔；ready_period 限制地址通道接收时隙；随机模式再增加固定 seed 的响应抖动与 READY 反压。读写通道独立，不能把它们的上限相加当作共享 DDR 总线。

| 配置 | latency | interval | ready_period | 随机额外等待 |
|---|---:|---:|---:|---:|
| ideal | 0 | 1 | 1 | 0 |
| latency20 | 20 | 1 | 1 | 0 |
| bandwidth16 | 0 | 16 | 1 | 0 |
| contended | 12 | 8 | 5 | 0–7、随机 READY |

四组在同一 K 投影、M=1/4 的输入上比较；额外重复同 seed，并用 seed 7 确认时序改变而结果不变。并未仿真刷新、bank/row、真实 DDR 调度或 FPGA 频率。

## 计数、正确性和证据

总周期从测试台准备释放控制写到观察 halted；`mcycle` 差值覆盖内核循环及末尾 fence。TCM 上传/回读在该窗口之外，原始总线记录保留其开销。首次外存请求延迟、读写 pending 周期和五通道 valid&&!ready 周期分别报告；pending 和 stall 可以重叠，不能相加当成互斥周期分解。

外存事件 trace 保存所有五通道握手、数据和时间戳；SV 每周期检查阻塞稳定性、属性和故障。Python 从原始输入逐笔核对读数据、从实际写事务重建全部 dots/Y，并交叉核对 SV 原始计数、TCM 上传/回读和完成状态。波形只保留计算开始的代表窗口，避免巨型全程波形。

有效 bytes/cycle、MAC/cycle 是该探针在指定内存条件下的仿真结果。条件字节下界使用 `max(read_bytes,write_bytes)*interval/16`，表示两个独立 128 位数据通道的理想容量约束；不包含延迟、指令、串行请求和规约。相对利用率也仅针对此模型上限。若引用 100MHz，必须写作假设频率换算，不代表 Fmax 或真实 DDR 带宽。

每个 run 保存独立目录、输入/源码/固件/RTL/checker/tool hashes、原始命令与日志、事件、计数和检查报告。负例损坏整数、FP32、读数据、完成标记或截断 trace 必须失败，且不能留下旧 PASS。评估支持仅表示此配置的仿真可行性，最终选择仍归 T08；板级频率、容量、资源和性能由后置任务验收。
